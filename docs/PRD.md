# PRD — vhk

## 한 줄 정의
바이브코딩 **풀사이클 하네스** — AI 코딩 한 바퀴(init→개발→검증→런칭→판매→운영)를
목표·증거·기억·규칙으로 묶어, AI 밖에서 결정론적으로 통제하는 한국어 CLI/MCP 도구.

## 정체성 — 풀사이클 × 하네스 (가로축 × 세로축)
VHK의 해자는 두 축의 **교집합**이다. 둘은 트레이드오프가 아니라 곱이다.

- **가로축 — 풀사이클**: 프로젝트 한 바퀴 전 구간을 커버한다.
  init → 개발(work/handoff) → 검증(goal/check/verify) → 런칭 → 판매 → 운영.
- **세로축 — 하네스(통제층)**: 각 구간에 AI 밖 결정론 레이어를 䣈다.
  규칙 단일소스(RULES.md→sync) · 증거 게이트(HARD_STOP) · 프로젝트 영속 기억(memory) · LLM 보안(secure).

경쟁 도구는 보통 가로 한 칸(특정 단계)이나 세로 일부(컨텍스트 주입만) 만 가진다.
VHK만 세로 통제층을 가로 전 구간에 관통시킨다 — "더 똑똑한 AI"가 아니라 "AI 밖 결정론 통제·신뢰 레이어가 제품 한 바퀴를 관통"하는 게 핵심.

### 차별성 4종 (모델이 똑똑해져도 잠식 못 하는 층)
| 층 | 내용 | 왜 안 잡아먹히나 |
|----|------|------------------|
| 결정론 게이트 | typecheck/test/build green 전엔 DONE 불가 (HARD_STOP) | 모델이 똑똑해져도 "증거 없는 완료"는 외부에서 막아야 함 |
| 크로스툴 규칙 통일 | RULES.md 단일소스 → 8개 도구 규칙 파일 동기화 | 도구가 늘수록 드리프트 비용↑, 단일소스만이 답 |
| repo 영속 기억 | .vhk/memory — 세션·도구를 넘어 프로젝트에 귀속 | 단일 세션 컨텍스트 창과 무관하게 살아남음 |
| LLM 보안 가드레일 | secure — 프로프트 인젝션·시크릿 누출 스캔(OWASP LLM Top10) | 모델 자체로는 보장 불가, 외부 결정론 검사 필요 |

## 문제 (Problem)
- AI 코딩 세션은 세션이 끝나면 맥락이 증발한다 — 다음 세션이 "어디까지 했지"부터 다시 시작.
- 규칙 파일이 도구마다 따로 논다(.cursorrules·CLAUDE.md·AGENTS.md…) — 한 곣을 고치면 나머지가 드리프트.
- AI의 "완료" 주장에 증거가 없다 — 게이트 없이 done 처리되면 거짓완료가 쌓인다.
- 비개발자 사용자는 영어 CLI·전문용어 장벽에 막힌다.
- 통제층이 개발 단계에서 끊긴다 — 런칭·판매·운영(뒷단)은 게이트 없이 손으로 처리돼, 한 바퀴가 닫히지 않는다.

## 해결 (Solution)
세션 의례(work/handoff) + 규칙 단일소스(RULES.md→sync) + 증거 게이트(goal/check/verify) +
프로젝트 기억(memory/recall)을 하나의 한국어 CLI로 묶는다. MCP 29 tools로 에이전트에서도 동일 동작.
이 통제층(하네스)을 개발에서 끝(런칭·판매·운영)까지 **같은 방식 — 게이트 강제 + 사람 승인 — 으로 연장**하는 것이 풀사이클의 정의다.

하네스를 런칭·판매·운영까지 세로축 방식(게이트 강제 + 사람 승인)으로 연장한다. 사실 상태는 goals/·CHANGELOG가 SoT.

| 단계 | 내용 | 상태 |
|------|------|------|
| 유입(SEO) | 사이트맵·IndexNow·GSC·GA4·AdSense·리포트·자동화 (goal 21~26) | 🔄 일부 착수 (21 완료, 22~26 진행) |
| 비용 가시성 | vhk cost — 세션 토큰·비용 계측 (GAP-05) | ⬜ 예정 |
| 비대화 모드 | --no-ai — CI/스크립트용 결정론 실행 (GAP-06) | ⬜ 예정 |
| 런칭·콘텐츠 | 릴리즈 노트·빌드로그 발행을 게이트+secure 통과 후에만 | ⬜ 예정 |
| 판매·운영 | 스타터킷 배포·결제·이상감지 운영 루프 | ⬜ 예정 |

## 성공 지표
- 세션 시작→작업 재개까지 1분 이내 (vhk work 프롬프트 1회 붙여넣기)
- 규칙 드리프트 0 (check-rules-sync 게이트 green 유지)
