Vibe Harness Kit · Big Picture

AI는 바뀌어도
개발 시스템은 남는다.

VHK는 새 AI 에이전트가 아니다. Codex·Claude Code·Cursor 같은 교체 가능한 실행자 위에, 저장소에 남는 목표·규칙·증거·기억·안전장치를 얹는 풀사이클 코딩 하네스다.

AI 모델 = 엔진 VHK = 차체 + 계기판 + 블랙박스 + 브레이크
AI가 구현한다어떤 모델이나 에이전트를 쓸지는 사용자가 고른다.
VHK가 흐름을 고정한다무엇을 할지, 정말 끝났는지, 다음 세션이 어디서 이을지를 저장소에 남긴다.
사람이 경계를 승인한다머지·배포·발행과 자율 실행 활성화는 끝까지 사람 게이트다.

한 번의 작업이 도는 방식

핵심은 명령어 수가 아니라 이 폐루프다. 한 번에 Goal 하나를 잡고, 말이 아닌 기계 증거로 닫은 뒤, 다음 실행에 교훈을 돌려준다.

01 · 방향 맥락 복구

VISION·context·이전 결정에서 왜 하는지 되찾는다.

02 · 선택 Goal 하나

선행 조건을 확인하고 지금 할 작업 하나만 고른다.

03 · 실행 AI가 작업

Codex·Claude Code·Cursor가 코드와 문서를 만든다.

04 · 증명 게이트 실행

타입·테스트·빌드·규칙·변경 증거를 실제 종료코드로 대조한다.

05 · 판정 완료 또는 정지

증거가 맞아야 done. 반복 차단은 HARD_STOP으로 멈춘다.

06 · 진화 기억과 규칙

실패·성공·결정을 쌓고 반복 패턴만 사람 승인 뒤 규칙으로 올린다.

저장소가 기억한다 세션 채팅이 아니라 파일이 진실의 원본이다.

VHK가 소유하는 다섯 층

여러 명령은 아래 다섯 책임을 구현하는 표면일 뿐이다.

1. 의도

Vision·Mission·Goal로 “왜, 무엇을” 고정한다.

2. 연속성

Context·Work·Brief로 세션이 끊겨도 이어간다.

3. 규칙 이동성

RULES 한 벌을 여러 에이전트 규칙 파일로 동기화한다.

4. 증거

Verify·Review·Receipt·Preflight로 “했다”와 “됐다”를 분리한다.

5. 학습과 안전

Memory·Pattern·Evolve·Policy·HARD_STOP으로 반복을 개선하고 위험을 막는다.

발행 경계는 어떻게 열리는가

구현 완료와 발행 가능은 다르다. 코드가 끝나도 실사용 관찰과 사람 승인을 모두 통과해야 다음 권한을 연다.

관찰 게이트

4주 + 10회

기간 4주와 유효 실행 10회를 모두 채우고, 최근 10회 실패 2회 이하·치명적 안전 위반 0을 확인한 뒤 사람이 계속/중단을 결정한다.

실제 진행률은 vhk stats와 2.x 로드맵에서 확인한다. 이 문서는 고정된 개념도이며 실시간 상태판이 아니다.

이 프로젝트의 진짜 전략

“좋은 기능인가?”보다
“사람이 다시 부르지 않아도 걸리는가?”

25시간 도그푸딩에서 막는 기능은 살아남고, 권고만 하는 기능은 방치됐다. 그래서 지금의 방향은 기능 수가 아니라 실행 조건과 증거의 자동화다.

의도적으로 하지 않는 것

  • VHK 자체가 LLM을 직접 호출하거나 모델을 고르지 않는다.
  • 대시보드 제품이 아니다. 코어는 CLI와 파일 계약에 집중한다.
  • 자동 머지·배포·발행은 현재 범위 밖이며 사람 승인 없이 열지 않는다.
  • 특정 벤더 세션에 규칙·기억·판정을 가두지 않는다.
  • 자가진화 후보를 자동 적용하지 않는다. 승격에는 사람 확인이 필요하다.
