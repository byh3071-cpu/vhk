# ADR-015: 사용자 출력은 상태·경과·다음 행동을 명확하게 말한다

> 상태: **Accepted — 2026-08-05 사용자 문구 검토 승인.**

## 한 줄 결정

VHK의 사람이 읽는 상태·경고 출력은 쉬운 말만 고르는 데 그치지 않고, 현재 상태와 경과 시간,
필요한 다음 행동을 구체적으로 구분해 보여준다.

## 맥락

`미착수 작업 7건 · 최고령 8일`, `반복 무시`, `미반영`처럼 짧지만 형식적인 표현은 숫자는
전달해도 어떤 작업을 말하는지, 얼마나 계속됐는지, 무엇을 해야 하는지 한 번에 알기 어렵다.
반대로 쉬운 말만 쓰고 대상이나 행동을 생략하면 정확성이 떨어진다.

## 결정

- 상태 요약은 대상과 현재 상태를 먼저 말한다.
- 시간이 중요한 알림은 등록 후 경과일이나 문제가 계속된 기간을 별도 줄에 표시한다.
- 사용자가 조치할 수 있는 문제는 `해결:`, `갱신:`, `확인:`처럼 다음 행동을 명시한다.
- 여러 정보가 있으면 한 줄에 압축하지 않고 의미별로 줄을 나눈다.
- 명령어, 옵션, JSON 필드, 안정 ID 같은 자동화 계약은 문구 개선 때문에 바꾸지 않는다.
- 합의된 형식적 표현은 용어 회귀 검사에 추가해 다시 섞이지 않게 한다.

## 결과

사용자는 출력만 보고 문제가 무엇인지, 언제부터 이어졌는지, 다음에 무엇을 실행할지 판단할 수 있다.
출력은 길어질 수 있지만 항목별 줄 분리로 읽기 부담을 줄인다. 기존 스크립트와 MCP 사용법은 유지된다.
