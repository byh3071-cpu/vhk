# ADR-008: 공개 VHK 코어와 개인 생태계의 경계를 분리한다

## 결정

VHK 공개 저장소와 npm 패키지는 개인 생태계 없이 단독 동작하는 범용 CLI로 유지한다. 사용자 규칙은 특정 저장소 구조가 아니라 직접 지정한 YAML 파일로 읽는다.

- 새 계약: `VHK_RULES_FILE` 또는 `~/.vhk/config.json`의 `rulesFile`
- 기존 `PRIVATE_RULES_ROOT`·`rulesRoot`·`set-rules-root`는 v2.12에서 경고와 함께 지원하고 v3.0에서 제거
- 공개 bootstrap은 VHK 자체 규칙만 생성하며 개인 저장소 자동감지나 교차 저장소 계약을 포함하지 않음
- 개인 운영 규칙·자동화·현재 상태는 비공개 저장소가 소유하고 범용 파일 계약으로 VHK에 연결

## 공개 기록 정책

제품 동작을 설명하는 ADR·RFC·CHANGELOG·재현 가능한 Dev Log만 공개한다. 개인 정체성, 다른 비공개 저장소 운영, 로컬 절대경로, 현재 작업 큐와 런타임 원장은 비공개 운영 기록으로 분류한다.

기존 append-only 기록을 공개 HEAD에서 제거해야 하는 경우 원본을 비공개 저장소에 먼저 보존하고, 이 ADR을 공개 경계 마이그레이션의 예외 승인 근거로 사용한다. 실제 삭제는 사람 승인 뒤 수행한다.

## 결과

- 공개 사용자는 관리자 생태계 없이 동일한 init·sync·MCP 흐름을 사용한다.
- 개인 환경은 한 릴리스 동안 기존 설정으로 동작하며 명시적인 이전 명령을 안내받는다.
- Git 이력은 전용 시크릿 검사에서 실제 자격증명이 확인될 때만 재작성한다.
