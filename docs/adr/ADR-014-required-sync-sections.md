# ADR-014: 전 타겟 필수 규칙 절은 RULES.md에서 선언한다

> 상태: **Accepted — 2026-08-05 Goal 120 실행 승인.**

## 한 줄 결정

모든 파생 규칙 파일에 반드시 들어가야 하는 절은 RULES.md 제목의
`<!-- vhk:sync=all -->` 표시로 선언하고, 동기화와 누락 검사가 같은 선언을 읽는다.

## 맥락

기존 `sync --check`는 디스크 파일과 현재 생성 결과만 비교했다. 생성기가 처음부터 안전 절을 빼면
양쪽이 똑같이 빠져 있어 검사를 통과했다. 필수 절 이름을 코드에 다시 적으면 RULES.md 변경과 목록이
어긋나는 같은 문제가 반복된다.

## 결정

- `## 절 제목 <!-- vhk:sync=all -->`을 전 타겟 필수 절로 해석한다.
- 필수 절 목록은 실행 시 RULES.md에서 파생한다.
- 생성기는 제목 분류와 관계없이 필수 절을 미러 8개에 넣는다.
- `sync --check`는 재생성 결과 불일치, 타겟 파일 누락, 필수 절 누락을 따로 센다.
- 실행과 미리보기는 `생성됨`, `변경됨`, `동일`이라는 같은 상태 어휘를 쓴다.

## 결과

안전 절을 새로 추가하거나 이름을 바꿔도 별도 코드 목록을 고칠 필요가 없다. 표시가 없는 절의 기존
선택적 전파 방식은 유지된다. 필수 절이 너무 길어 특정 도구 제한으로 잘리면 검사가 실패하므로,
필수 절은 짧고 핵심적인 규칙으로 유지한다.
