## 전략 판정 (2026-07-13)

"최적화 vs 전진"은 거짓 이분법 — 답은 **순서**: ①출고 → ②정합화+계측 스위치온 → ③전진(감사층 → Wave 2 → 불가지론화).

- 드리프트 수동 수정은 재발이 실증됨(RFC 0058 자기 헤더가 드리프트) → 수동 1회 + **자동 재발방지(RFC 0062, 드리프트 자동감지)**가 한 세트.
- measure-first 헌법 vs 실측 0 모순이 백로그 절반(goal 50 PR2·65·RFC 0049 kill-gate)을 잠금 → 계측 재가동이 신기능의 임계경로. 계측 인프라는 goal 88~100으로 완공 — 짓는 게 아니라 켜는 것.
- ⚠️ RFC 채번: **0059 = UX 6흐름·command manifest 예약**(next-task 2026-07-06 확정) — 드리프트 감지는 **0062**.
