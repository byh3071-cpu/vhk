# 빌드 산출물을 실행하는 E2E는 빌드 뒤에 실행한다

## 증상

소스 모듈을 직접 불러오는 단위 테스트는 통과하지만, **dist/index.js** 같은 산출물을 새 프로세스로 실행하는 E2E만 파일 없음 오류로 실패한다. 코드 회귀처럼 보이지만 빌드 후 같은 테스트를 다시 실행하면 통과한다.

## 원인

테스트 명령이 모든 테스트의 입력을 직접 준비한다고 가정했기 때문이다. 실제로는 일부 E2E가 빌드 단계의 출력을 소비하므로 **test**가 **build**에 의존한다.

## 해결

- 통합·CI 게이트의 실행 순서를 **build → test**로 고정한다.
- E2E 코드에서 소비하는 산출물 경로를 한 곳에 명시한다.
- 산출물 없이도 돌아야 하는 테스트와 빌드 결과를 검증하는 E2E를 구분한다.
- 실패 시 먼저 산출물 존재 여부를 확인하고, 존재하면 실제 기능 회귀를 조사한다.

## 적용 조건

TypeScript 번들, 네이티브 바이너리, 생성 코드처럼 빌드 결과를 child process로 직접 실행하는 테스트에 적용한다. 소스만 불러오는 단위 테스트에는 불필요하다.
