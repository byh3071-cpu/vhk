# Definition Packet — 대화형 정의 템플릿

> 상태: 사람용 Markdown 템플릿.
>
> parser, JSON schema, 저장 위치와 새 CLI를 정의하지 않는다.

## 사용 목적

아이디어나 긴 대화를 바로 구현하지 않고, 실제로 만들기로 결정한 뒤 다음 에이전트가 다시 전체
대화를 읽지 않아도 되도록 핵심 의도와 회색 영역을 정리한다.

## 대화 진행 규칙

1. AI는 먼저 이해한 내용을 5줄 이하로 쉽게 다시 말한다.
2. 구현 방향을 가장 크게 바꾸는 질문 **하나만** 묻는다.
3. 선택지 2~3개, 추천안과 이유를 함께 제시한다.
4. 사용자 답을 결정 또는 되돌릴 수 있는 가정으로 아래 패킷에 기록한다.
5. 조사로 답할 수 있는 사실은 먼저 공식 자료·코드·실측으로 확인한다.
6. 높은 영향의 열린 질문이 0개가 될 때까지 1~5를 반복한다.
7. 마지막에 “쉬운 요약”과 “상세 패킷”을 함께 보여주고 사용자 확인을 받는다.

AI의 내부 사고 과정은 기록하지 않는다. 결정, 근거, 확인한 사실, 실패와 남은 위험만 남긴다.

## 13. 준비 상태
