## 계측 스위치온 (Phase 1 트랙 B — 이 세션에서 개시)
- **receipt 적발률 90일 측정 개시일 = 2026-07-13.** 정의는 RFC 0056 그대로(90일 내 거짓완료 적발 1건 = 단일 성공기준, 0건이면 가설 폐기). 카운트 규칙: receipt 검증 실패(block/caution)가 "완료 주장"을 뒤집어 수정을 유발한 사건 1건 = 적발 1.
- **0일차 기준선(`vhk stats --trend`, main 실데이터)**: receipt 발행 1(block 1·caution 0·pass 0) · 게이트 red 0% · dirty 100% · diff-cover 측정 없음 · evolve 채택률 표본 0 · check 위반수 표본 0 — measure-first 선언 대비 실측 0 을 수치로 확정.
- **계측 DB 재가동**: 노션 "바이브코딩 워크플로 계측"에 순수 VHK 행 최초 적재(0일차, 판독 1줄 포함). "VHK" select 옵션은 기존재 — 옵션 추가(사람 승인 대상) 불필요했음.
- **주간 루틴 확정**: 주 1회 `vhk stats --trend` 스냅샷 → 계측 DB 프로젝트=VHK 행 + 판독 1줄("이번 주 데이터가 해금/반증한 것") 필수. Recall 라벨은 실쿼리 자연 누적만(합성·소급 금지).
