## 교훈

1. **빌드타임 인라인 < 런타임 read** — `commander.version('0.8.0')` 같은 리터럴은 publish 자동화 시 dist와 package.json 불일치. 런타임에 package.json 읽는 게 single source of truth.
2. **대화형 인증은 stdio inherit 필수** — 2FA(OTP / WebAuthn / Windows Hello)는 spinner + pipe로 가리면 사일런트 실패. spinner 중단 + inherit으로 사용자에게 보여줘야.
3. **Node 메이저+마이너 보안 패치 회귀 주의** — Node 20.12+ CVE-2024-27980은 `execFileSync('.cmd')` 직접 호출 거부. 기존 코드가 깨질 수 있음.
4. **모호 발화는 null이 안전** — NL 라우터에서 의도 불확실하면 매칭 안 시키고 메뉴 안내가 잘못된 명령 실행보다 낫다.
