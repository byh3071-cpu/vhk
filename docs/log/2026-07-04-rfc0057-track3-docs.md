## 교훈

- RFC 0055(archived) 같은 "폐기된" 문서도 완전히 죽은 문서가 아니다 — 0056이 "결함 정정 후 재사용"이라고 명시한 부분(§3·§4·§9)이 실제로는 재사용되지 않고 조용히 유실될 수 있다는 걸 이번에 확인했다. 후속 RFC를 쓸 때 "이전 RFC가 재사용하겠다고 말한 부분이 실제로 재사용됐는가"를 코드로 직접 대조하는 습관이 필요하다.
- "발견 사실만 기록하고 고치지 않는다"는 스코프 경계(트랙①·②는 별도 트랙이 처리)를 지키려면, 문서에 "이미 고쳤다"처럼 읽히는 과거형 서술을 쓰지 않도록 주의해야 한다 — 이 RFC에서는 트랙①·②를 전부 "병행 진행 중"으로만 서술하고 구체 결과는 병합 후 채우도록 자리만 남겼다.
