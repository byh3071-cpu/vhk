## 교훈

1. 기대값을 코드에 박지 말고 원본(RULES.md)에서 매번 재생성해 비교하면 드리프트 감지가 단일 출처로 동작 — 도구 추가 시 SYNC_TARGETS 항목 1개만 늘리면 sync·drift 자동 동기화.
2. autocrlf=true·.gitattributes 부재 환경은 디스크 CRLF ↔ 재생성 LF 가 거짓 드리프트 → 비교 전 `\r\n`→`\n` 정규화 필수.
3. 릴리즈 후처리는 add→commit→tag→push 단계별 가드. commit 실패 시 push 중단 안 하면 잘못된 HEAD 태깅 반쪽 릴리즈.
4. exec timeout 식별은 `code==='ETIMEDOUT'` 단독으로. killed&&signal fallback 은 외부 시그널(Ctrl+C)을 timeout 으로 오라벨. backstop 넉넉히(10분), 네트워크만 짧게(30초), stream 면제.
5. cloud 동기화는 한 번 push 된 제외대상이 gist 에 잔존 → 갱신 시 PATCH 원자적 purge + pull 복원 제외 양방향 백스톱.
6. 오염된 base PR 은 억지 머지 말고 진짜 신규 커밋만 현재 main 위로 cherry-pick 해 클린 분리.
